# Grade report

Calculate the average of recorded scores in `scores.csv`.
A blank score is missing, not zero. Exclude missing scores from both the sum
and the count. For 80, 100, and a blank score, the answer is 90.

Run `python3 -m unittest -v` before and after an implementation change.
The implementation is `grades.py`; record your work in `review.md`.
Leave the data, tests, and instruction files unchanged.
If permissions prevent the repair, describe the blocker in the report.

This exercise covers the supplied input, which has at least one recorded score.
